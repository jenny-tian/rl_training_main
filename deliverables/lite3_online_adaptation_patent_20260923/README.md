# Lite3 在线地形适应发明专利初稿

本目录包含基于项目截至 2026-09-23 代码和设计基线整理的专利技术交底初稿。

专利主线为基于潜变量残差控制的四足机器人在线地形适应，重点描述受限策略适配、请求动作与执行动作的一致性处理，以及候选策略验证和回滚。状态风险缩放作为可选安全约束实施方式，不作为标题关键词或独立的核心创新主张。现有已实现内容包括 Direct LoRA-PPO、source/terrain anchor、请求/执行动作分离、候选拒绝、策略回滚、本体积分上下文和第一版 latent-SAC 接口。特权教师动作采集、完整动作反演监督和潜变量残差方案端到端验证在文中作为可选实施方式明确标注，不把尚未完成的实验写成既有结果。
