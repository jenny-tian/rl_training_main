## 直接阻塞修复与性能修改

旧 G3 的完整记录止于控制步 506。重建该步宽扫描和步 507 的 root 位置/朝向，
环境 34、射线 322 的 local x 从 -1.495816 m 移到约 -1.500541 m，越过有限
地形后边界 -1.5 m；此结果是根据保存状态计算的投影，不是原异常时命中值的
直接观测。旧报告只包含通用 nonfinite scanner evidence，原件保持不变。

训练配置新增宽扫描 footprint 的提前终止保护：原刚体碰撞包络检查保留，另
检查 yaw 旋转后的扫描范围及下一控制步预测，使用 0.1 m 内缩余量。半宽
0.87/0.57 m 包含原 1.6×1.0 m 网格及一个 0.07 m 采样间距。普通终止通过
原 source_terrain_tile_bounds 条目记录/reset；非有限值、错误命中归属、
实际越界和跨环境接触仍为硬错误。G3 逐子步记录并由 CPU 重算新增保护。

G3 首次及每次实际 reset 后重建完整接触路径映射，普通运动不反复解析 421 万
个配对；原生 contact view 的身份、stage、backend 和维度持续检查，每个物理
步的完整 dense force/count 有限性、稀疏联合集和重建检查保留。独立 CPU
解码器验证并私有保存 topology 一次，每帧仍重建并核对 dense SHA。

事件中的 tensor 使用有界 little-endian/base64 无损编码，外层仍为分成员
gzip JSONL；解码恢复原 dtype/shape/values。旧记录读取继续支持。首次扫描
错误补充传感器名、字段、环境/射线索引和原始状态，NaN/Inf 显式字符串保存，

独立地形成功率或正式选模资格。
