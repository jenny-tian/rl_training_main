## 台阶的复用方式

直接调用已安装 Isaac Lab 的 `MeshPyramidStairsTerrainCfg`、`MeshInvertedPyramidStairsTerrainCfg` 及其网格生成函数，不复制修改系统库。

| 项目 | 拟定设置 |
|---|---|
| 台阶形状 | 中心平台及四周环形台阶，沿用原生生成方式 |
| 单级高度 | 0.035 m，与当前 L2 一致 |
| 踏面宽度 | 0.5 m，与当前 L2 一致 |
| 一次从中心走向外侧的高度变化 | 5 级，累计 0.175 m；以生成网格实测为准 |
| 初始生成参数 | `size=(8,8)`、`border_width=1`、`platform_width=3`、`holes=False` |
| 出生位置 | 中心平台，z 使用生成器返回的实际平台高度加 0.375 m 离地高度 |
| 下台阶 | 中心高的 pyramid 从中心向外走 |
| 上台阶 | 中心低的 inverted pyramid 从中心向外走 |

原生生成器的 `platform_width` 参与台阶数的取整，不能直接当作最终平台的精确宽度。按当前函数计算，上述参数产生 4 圈踏面，中心到外部平地经历 5 次高度变化，中心平台宽约 2 m；B1 必须用网格采样核验后才能试训。参考配置默认的 0.05–0.23 m 高、0.3 m 踏面不直接照搬，否则超出本项目 L2。

提案准备中的只读 CPU 核验已确认上述尺寸：从安装源码提取未修改的两个生成函数及 `make_border`，生成真实三角网格；两种地形各 21 个盒体网格，中心平台实测 2×2 m。中心向东、南、西、北的四条剖面均为 5 次 0.035 m 高度变化，中心高度分别为 +0.175/-0.175 m，距中心 3.25 和 3.4 m 处均回到外部平地高度 0。源文件 `mesh_terrains.py` SHA256 为 `50c1bbc1b319c71cb9a3305f4c52211be9e8c8db9859949e9784806fc26806c3`。这是几何可行性核对，尚未构建新训练任务，也未验证机器人在该地形上的动力学表现；B1 仍须执行完整仿真检查。

每次台阶回合从四个轴向出口之一行走，机器人出生朝向与出口对应，避免沿对角线跨过角点改变踏面间距。其他坡面及横坡也须将几何方向、出生姿态和指令方向成套设置，保证标签与实际坡向一致。
