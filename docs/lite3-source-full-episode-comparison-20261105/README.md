同一时刻，候选横向偏移绝对值增加 0.168–0.242 米，偏航绝对值增加 1.41–2.32 度。原模型自身也在漂移，但这五个环境随后仍成功完成。环境 73 已超过 9 米，稳定保持只有 18 步，未达到 50 步。

代码与记录支持以下解释：

- [线速度奖励](../../source/rl_training/rl_training/tasks/manager_based/locomotion/velocity/mdp/rewards.py) 的 `track_lin_vel_xy_exp` 比较指令与 `root_lin_vel_b`，即机身坐标系线速度。记录的速度误差使用同一定义。航向偏离通道后，机器人仍可能保持机身前向速度接近指令，同时累积世界坐标系横向位移。
- [奖励配置](../../source/rl_training/rl_training/source_scan/adaptation_profile.py) 有角速度跟踪和姿态等项，但没有直接的通道横向位置或绝对航向误差奖励。零偏航角速度跟踪约束转动速度，不能直接保证已积累的航向误差归零。
- [运行日志](raw/runtime/runtime.log) 的 policy 观测表是 45 维：角速度 3、投影重力 3、速度指令 3、关节位置 12、关节速度 12、上一动作 12。没有直接的通道横向位置或绝对航向观测；投影重力也不提供绝对偏航信息。

证据表明任务完成目标、观测与速度指标之间存在缺口，能解释速度奖励良好与越界共存。尚未证明某个奖励权重、摩擦物理参数或优化器因素是唯一原因，也不能认定只改奖励就足以解决。两轮训练每环境共采样 0.96 秒，先前复评仅 8 秒；此次新增失败发生在 28–30 秒，短时通过不能替代完整回合验证。

**边界诊断的证据范围。**

越界项是刚体边界检查与扫描器覆盖范围检查的逻辑或，两者均有当前状态和下一步预测分支。机器人中心仍在地形内，也可能因身体或扫描覆盖范围而终止。

利用保存的根节点 x、y、yaw，按 [scanner_boundary](../../source/rl_training/rl_training/source_scan/scan_footprint.py) 的半尺寸 (0.87, 0.57) 米和 0.1 米余量重建当前扫描矩形，五个候选结束点的最小边界余量约为 -0.16 至 2.09 毫米，与靠近覆盖范围边缘一致。

这是几何重建，不是运行时分支记录。未保存全部刚体姿态、完整世界速度，也未启用相应观察器，无法精确区分刚体、扫描器当前或预测分支的首个触发来源。负余量表示重建的当前矩形超出允许范围，不据此认定唯一终止来源。

详见 [new_failures.csv](deliverables/new_failures.csv)、[failure_analysis.json](deliverables/failure_analysis.json)、[new_failure_trajectories.png](deliverables/new_failure_trajectories.png)。轨迹图只画首回合，前进与横向坐标使用独立比例。
