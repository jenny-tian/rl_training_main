2. 比较三个模型在同一观测上的关节目标和动作变化。重点看 159 从行走到静止前后、189 后足进入末级前后、221 横移及倾斜发生前，并对完整 240 起点作分组核对，避免只挑失败案例。分析前后腿、左右腿及关节分别出现什么变化，是否存在动作/关节目标裁剪或饱和。单步动作差只作为定位证据，不当作换模型闭环运行后的结果。
3. 检查已有训练记录中的优化变化。对照 A/B 的实际学习率、策略损失、价值损失、熵、梯度/KL 等可用字段及对应源码；缺失的历史字段不补造。核对共有配置如何根据不同 rollout 调整学习率，区分数值异常、训练目标取舍与正常的策略分化，不能仅凭 A 学习率较大就认定它是根因。
4. 对照停步与行走时的奖励条件。先区分冻结评测的公共参考计分和训练实际使用的台阶奖励。能够准确复算的部分检查时序、适用条件与符号；训练奖励的隐藏状态或传感器未记录时，明确证据缺口，不把评测奖励当作训练收益或策略梯度。现有轨迹上的分数差只能说明奖励偏好，不能证明改奖励后的成功率。
