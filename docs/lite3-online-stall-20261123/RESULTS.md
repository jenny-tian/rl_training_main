## 4. 学习过程

- 两个摆动幅度（tanh 后）在 4 次尝试时是 0.98、0.99（上阶）和 0.95、0.98（箱体），之后停在上限 0.99。
- 窗口受阻比例的平均值：上阶前腿 0.50、后腿 0.65，箱体 0.52、0.57。高于目标值 0.30 的窗口占 99%、88%（上阶）和 95%、87%（箱体），所以幅度一直被往上推。
- 训练中 Updated 组的成功率：上阶 27%（Frozen 组 7%），箱体 32%（Frozen 组 16%）。

## 6. 说明

- 这个学习器到达的是把两个摆动幅度加到上限的参数，相当于库里两组上阶参数的水平。箱体上最好的库参数带有固定偏置，它不学固定偏置，所以差 28 个百分点。
- 受阻比例在这两个地形上始终高于目标值，学习器没有表现出在某个幅度停下来的行为。目标值和增益是否合适，在受阻比例会降到目标值以下的地形上才能检验。
- 每个目标训练 10000 步、含评估共 933.6 万次环境交互。两条运行链 20:38 启动，21:41 和 22:00 结束，期间 GPU 与其他五个训练共用。
