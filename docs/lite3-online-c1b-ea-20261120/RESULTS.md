# C1-b-EA 结果：6 cm 与 6.5 cm 上阶

2026-11-20 完成。方案和判定条件见 [PLAN.md](PLAN.md)，训练前提交（`eb995d9`，运行方式的修订在 `7c3ce3f`）。逐项数字在 `RESULTS_stairs_up_06.json` 和 `RESULTS_stairs_up_065.json`。

## 1. 结论

- **主判定两个目标都未通过。** 执行感知的探索标准差学到的参数，与固定标准差的做法二没有可以分辨的差别：60000 步时两个目标都是 −2.9 个百分点，区间跨过 0。
- **按五项判定，EA 自己仍然全部满足**（对本轮 Frozen，60000 步）：6 cm 上阶 126 → 165，6.5 cm 上阶 59 → 112。
- 至此 C1-a → C1-a-EA → C1-b → C1-b-EA 四个阶段全部做完。两个 EA 变体都没有显示出超过固定探索的收益。
- 新增的早期快照给出了学习速度：做法二约 36 次尝试时已拿到最终增益的大部分（第 5 节）。

- 标准差确实按方案变化了：Updated 组约 95% 的轮次求解成功，其他回退情形一次都没有出现。
- 实际效果与训练前的预估一致：参数学到 1 左右以后两个方向都进入低响应，标准差从 0.7 降到 0.5 到 0.55，更新步长同比例变小。参数偏离均值的均方根从 0.70 降到 0.56 到 0.60。
- 前腿和后腿的执行比例差 0.03 到 0.09，这点差别不足以让两个方向得到明显不同的探索量。
- 每个会话的更新次数与做法二相同（57 次）。训练回合的成功率（带探索，按时间三段）：6 cm 59% → 67% → 67%（做法二 60% → 67% → 67%），6.5 cm 35% → 43% → 46%（做法二 37% → 47% → 47%）。

- **做法二在约 36 次尝试（9 次更新）时的增益是 +15.8 和 +19.2，是 60000 步增益的 82% 和 77%。** 17 次尝试时是 +5.8，区间包含 0。
- 36 次尝试之后增益在 +14 到 +25 之间波动，没有稳定上升。所以这个学习器的问题有两个：前 36 次尝试偏慢；之后停在 6 cm 约 70%、6.5 cm 约 50% 的成功率上不再提高。
- 学到的参数（tanh 后的均值，前腿 / 后腿）：做法二在 5000、10000、20000、60000 步是 0.31 / 0.17、0.50 / 0.29、0.70 / 0.51、0.82 / 0.64（6 cm）；EA 是 0.26 / 0.14、0.48 / 0.19、0.67 / 0.39、0.84 / 0.53。后腿学得比前腿慢，EA 的后腿更慢。

## 6. 局限

- EA 的公式系数取研究方案原值，没有调过；协方差的参考点取在当前均值上。结论是这一组设置下没有收益。
- 60 个会话能分辨的差别约 ±9 个百分点，更小的差别本实验看不出来。
- 其余局限与做法二相同：动作形式由人给定；摆动判断用仿真里的足端接触力，地形判断用真实地面高度；结果只对 B10200 和仿真成立。
