## 修正后为什么仍触发

仍然是 **`FL_THIGH`，body ID5，Y 轴预测分支**。当前分支未越界，索引有效，输入有限。区别在于本次位置与速度确实属于同一个 link 原点：

| 末步量 | 数值 |
|---|---:|
| 当前 link 原点 Y | 1.7263942957 m |
| 安全中心上界 Y | 1.7289999723 m |
| 当前位置余量 | 2.605677 mm |
| COM 世界 Y 速度 | 0.1870189607 m/s |
| 修正后的 link 世界 Y 速度 | 0.1958213151 m/s |
| 旧混合参考点预测 Y | 1.7301347256 m |
| 本次正确参考点预测 Y | 1.7303106785 m |
| 旧预测／本次预测超出量 | 1.134753／1.310706 mm |

本次完整记录了大腿 COM 偏移 `[-0.0039245002,-0.0146319997,-0.0251460001] m`、四元数及角速度；实际偏移与 USD 静态审计逐值一致。CPU 使用独立旋转矩阵／分量叉积核对 `v_link = v_COM − ω × Rr`，再按原 float32 精确回放全部 **1059 次谓词**。全部 **18003 个刚体状态**的换算通过，最大速度核验差 1.181e-7 m/s，最大 COM 位置核验差 2.433e-7 m；无不可核验帧。

因此，本次停止不能仅归因于原来的位置／速度参考点混用。修正后同一预测仍超界，而且末步超出量增加约 **0.176 mm**。这仍是安全包络的一步线性预测，不能据此宣称真实刚体已经跨过地形边缘，或证明下一控制周期必然越界。
