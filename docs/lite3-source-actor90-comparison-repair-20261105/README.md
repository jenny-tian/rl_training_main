## 修复依据

安装的 IsaacLab 普通 USD 场景关闭路径清理环境和 SimulationContext 单例，但不
停止时间线。第二个 SimulationContext 在进入 Isaac Sim 父构造函数之前注册 STOP
回调；父构造函数发现时间线仍在播放时调用 stop。STOP 回调会持续 render 并等待
恢复播放，构造函数因而无法继续。这与上一轮 old/2000 后无第二次 initial-ready、
CPU 忙而 GPU 空闲的现象相符。上次没有可用的运行时栈，本次用阶段记录进一步核验。

修复仅作用于结束后的环境生命周期：先保存 actor 首回合指标，临时关闭待销毁
上下文的停止事件等待，再调用正常 stop 和 close，创建空 USD 场景后构造第二个
环境。IsaacLab 安装文件未修改；环境配置、控制动作、奖励、安全和扫描检查不变。
实际初态哈希、地形分配和原点仍必须相同，才能形成有效配对。

另增加每个场景 120 秒启动、15 秒关闭期限，以及进程内 Python 栈自动保存，
避免下次停滞时只剩一份启动快照。
