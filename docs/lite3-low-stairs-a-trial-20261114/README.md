## 抬脚与接触的现有证据

固定参数 5 cm、0.32 m/s 的 40 次前脚首次接近中，原模型与 A 都有 40/40 足底低于首级台面。足底相对台面的中位高度从 −4.54 cm 变为 −4.02 cm，尚未形成稳定的提前抬脚跨过立面行为。

有效落脚样本从 31/40 提高至 40/40；在有有效落脚的样本内，首次接近到落脚的中位时间从 2.04 秒缩短至 0.16 秒。这支持低速接触后的处理改善，但两组有效落脚样本数不同，不能当作全体严格配对的时长效应。

首次超过 20° 倾斜前的碰阶足帧比例均值，低速为 18.6%→11.0%，高速为 13.1%→15.9%。低速累计碰阶足秒反而为 2.63→5.49，因为两组观察时长和走过的阶数不同，不能笼统声称碰撞时长减少。这里使用几何与力的代理判定，20 ms 采样，并非精确重放训练中的射线奖励，也不构成唯一因果解释。

逐回合与足端数据见 [contacts_before_tilt.csv](contacts_before_tilt.csv)、[first_front_approaches.csv](first_front_approaches.csv)。

## 训练覆盖与最终核验

最终全局平均地形等级 5.937，原模型结束时为 5.764。按实测每级高度至少 4 cm 统计，本轮上阶累计 977481 个环境控制帧，占上阶样本 19.87%；下阶为 810369 帧，占 16.51%。这些高阶区域中，新增碰阶项分别在 17256、3766 帧触发。因此不能把当前退化简单解释为没有见过较高台阶；有限预算、课程重建和单个训练种子的限制仍然存在。

训练最后 100 次的日志姿态终止指标平均约 1.06%，属于混合地形训练统计，不等于固定 5 cm 高速上阶的失败率。所有损失和参数检查通过。

六组评估的全部初始数组与冻结基线相等，公共配置一致；策略身份和不参与确定性动作采样的学习方差单独记录。原生 actor 与评估适配 actor 在 2048 个随机输入和 320 个真实输入上最大差为零。所有正式运行无已检测的物理回退、接触丢失或运行错误。两段录像的全部初始数组、轨迹和回合记录与正式运行完全一致，视频解码通过。原低台阶、高台阶和 core 模型哈希均未改变。

## 下一阶段建议，等待批准

建议先定位高速上阶与左转退化开始出现的阶段，不直接延长 A，也不把 A 与 B 合并训练。拟使用已保存的新增 100、250 次检查点，与现有 0、500 次结果比较：在 GPU 1 分别运行固定参数上阶 240 回合和固定参数转向 320 回合，共新增 1120 个冻结首回合，零 PPO 更新。预计仿真与整理约 15–30 分钟，实际以运行耗时为准。
