# 相同 100 次更新的冻结对照

用户已批准本阶段。只评估旧净空试验保存的 10100 检查点，新增训练次数为零。

## 范围与执行约束

- 新增 1360 回合：名义和训练随机化转向各 320；名义和训练随机化上阶各 240；名义上阶加世界 +x 航向反馈 240。
- 每个条件 20 个固定起点；原台阶高度为平地、2、3、5 厘米，速度 0.32、0.4、0.6 m/s。
- 沿用现有冻结评估代码、确定性均值动作、统一参考奖励计分、第一回合和重置前轨迹口径，不改原协议成功标准。
- 航向反馈仍为增益 0.5、限幅 0.8 rad/s，不加横向位置反馈，单列诊断结果。
- GPU 1 顺序运行，启动前空闲显存至少 10240 MiB；不停止其他任务。
- 复用父模型 10000、组合模型 10100 的既有结果；旧净空 10500 只作为延长训练的背景对照，不混入相同更新数的主要比较。
- 验证历史训练报告、检查点哈希、Adam 步数、源码、初始数组、仿真配置与推理适配，保留所有失败与存活样本数量。
- 不修改历史训练、奖励、恢复或评估文件。新增脚本和报告独立保存。

## 分析口径

1. 全部起点的前 2 秒姿态终止、命令后的姿态终止、新增及恢复的配对失败。
2. 4–8、10–14、16–20 秒转向误差及实际角速度，主表使用三个模型均完成时间窗的共同样本，另保留两两配对结果。显式列出分母，避免因先跌倒而只比较幸存者。
3. 按台阶高度和速度统计完整通过、姿态终止、横向越界、卡住与超时，航向反馈单独比较。
4. 从 5 厘米轨迹提取停滞时点、前进位移、首次较大倾斜和碰阶代理。碰阶是 20 ms 采样的几何/足端力代理，不是物理接触流形或因果证明；报告倾斜截断与暴露时间。
5. 相同更新数只控制训练长度。组合模型还同时改变转向奖励、命令采样、动作保持，且采样轨迹不同，不能把差异单独归因于某一项。
