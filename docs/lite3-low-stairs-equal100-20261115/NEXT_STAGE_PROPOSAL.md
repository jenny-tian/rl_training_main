# 下一阶段候选：单独关闭动作保持损失

本文件为待批准方案。本阶段没有实施该改动，也没有启动训练。

## 要回答的问题

相同 100 次更新后，净空单项和组合模型的上阶及左转表现不同。组合模型在净空之外还增加了转向奖励修正、持续转向命令、父模型动作保持，当前对照不能拆出三项各自的作用。

建议下一次相对组合试验只改变动作保持系数：从 0.5 改为 0。这样能直接检查这一辅助损失是否参与了上阶退化，并量化撤去它后站立和转向的变化。该试验用于定位原因，不保证会得到可部署模型。

## 固定范围

- 从同一个父模型 10000 重新恢复 actor、critic、Adam 和课程分布。训练种子 42、GPU 1、4096 环境，原 PPO 参数与六类低台阶地形保持一致。
- 保留持续净空、纯转向短摆脚负奖励修正、持续左右转命令覆盖，参数与组合试验完全一致。
- 使用相同独立训练样本库、五组样本和采样游标计算路径，只把辅助损失系数设为 0；不重新采集样本，不把验收轨迹用于训练。
- 新增独立配置和训练入口，不修改已归档的历史源文件。先做 CPU 检查及零更新物理集成检查，再执行最多 100 次 PPO 更新，保存 50 和 100 次检查点。
- 总预算 100 次更新，即 9,830,400 次环境交互、2000 个 Adam 步。非有限值、仿真致命错误、恢复或预算核验失败立即停止，不自动重启。结束后不继续到 200 或 500 次。
- 物理回合和 RNG 重新初始化；不能把不同训练分支描述为逐帧相同的连续训练。

## 冻结验证与决策

最终 10100 检查点执行原协议 1600 回合：两种物理条件下转向各 320，上阶和下阶各 240；另做名义上阶航向反馈 240 回合。复用既有父模型、组合 10100 和净空 10100 的结果，使用相同初始数组和配置。

对比重点：5 厘米上阶按三档速度的完整通过数、姿态终止与卡住；随机化起步失败；六档持续左右转的配对误差、实际转速及失败数；2/3 厘米和平地/下阶保持。航向反馈仍单列，不能替代原协议表现。

定位结论与能力验收分开：即使证实去掉辅助损失改善上阶，只要转向或站立出现明显退化，就不提升为基线。沿用现有验收要求，不通过降低阈值宣布成功；不根据单训练种子作广泛泛化结论。

阶段结束后详细汇报，再由用户决定是否开展下一项改动。批准本方案不包含自动延长训练或部署。
