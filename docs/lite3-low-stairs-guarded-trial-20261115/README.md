## 站立恢复与转向

所有转向测试都在同一物理设置内使用与父模型完全相同的初始数组。前 2 秒为零命令。随机化起步包含默认 PD 准备后存在倾斜的状态，因此它同时检查恢复能力。

| 指标 | 父模型 10000 | 本次 10100 |
|---|---:|---:|
| 名义前 2 秒姿态终止 / 320 | 0 | 0 |
| 随机化前 2 秒姿态终止 / 320 | 3 | 2 |
| 随机化命令发出后的姿态终止 / 320 | 1 | 0 |
| 两种设置中新出现的配对姿态失败 | — | 0 |
| 名义高速左转误差，4–8 秒，rad/s | 0.19983 | 0.26760 |
| 随机化高速左转误差，4–8 秒，rad/s | 0.17435 | 0.23176 |

高速左转命令为 +0.8 rad/s，名义/随机化的误差分别增加 33.9% / 32.9%，且每组 20 个配对起点全部变差，触发中途停止。名义实际左转速度从 0.606 降到 0.536 rad/s，随机化从 0.654 降到 0.582 rad/s，主要表现为转得更慢，并非这两组发生跌倒。

标准 ±0.5 rad/s 命令也不能简单概括为恢复正常：名义左转误差 0.30904 → 0.33727，右转 0.24492 → 0.26787；随机化左转 0.29351 → 0.31108，右转 0.24283 → 0.21674。低速 ±0.2 rad/s 命令下，名义模型和父模型仍几乎不转。

原完整验收的 96 个配对时间窗中有 22 个相对误差增加超过 10%。其中包括停止后极小绝对误差的相对增幅，不应把 22 个都视为同样严重；高速左转在 4–8、10–14、16–20 秒均出现实际明显退化。完整数据见 `turn_paired.csv`。

上一次净空 10500 模型的随机化起步终止为 23/320；本次为 2/320。在未用于本次训练的原诊断样本上，恢复动作的关节目标 RMS 偏移由上次约 0.3039 rad 降至本次 0.0343 rad，其他四组约 0.0064–0.0078 rad。这支持动作偏移得到了限制，但单步动作相似不能保证连续转向性能保持。

## 原协议台阶完成数

每格均为 60 回合，三个速度 0.32、0.4、0.6 m/s 各 20 个起点。完成数要求走完整段，不能用跨过第一阶代替。

| 物理设置 / 方向 | 平地，父 → 新 | 2 厘米，父 → 新 | 3 厘米，父 → 新 | 5 厘米，父 → 新 |
|---|---:|---:|---:|---:|
| 名义 / 上阶 | 60 → 60 | 60 → 60 | 54 → 57 | 18 → 9 |
| 名义 / 下阶 | 60 → 60 | 60 → 60 | 60 → 60 | 60 → 60 |
| 随机化 / 上阶 | 45 → 51 | 43 → 50 | 40 → 51 | 37 → 48 |
| 随机化 / 下阶 | 44 → 51 | 45 → 51 | 45 → 51 | 39 → 52 |

名义 5 厘米上阶分速度为：0.32 m/s 的 0 → 0，0.4 m/s 的 4 → 3，0.6 m/s 的 14 → 6。姿态终止总数 22 → 19，但卡住 6 → 17、超时 3 → 7，因此跌倒稍少不等于上阶能力改善。名义 3 厘米姿态终止 5 → 0。

随机化 5 厘米上阶姿态终止 1 → 0。随机化下阶矩阵的平地对照新增 1 次姿态终止，完成数提高并不意味着每个起点都改善。两种物理设置使用不同的固定条件，不能据此推断增加随机化必然更容易上阶。

## 航向反馈诊断

这 240 回合单独加入世界 +x 航向反馈，增益 0.5、角速度限幅 0.8 rad/s，没有横向位置反馈。物理初始数组保持相同，实际命令与前一帧朝向计算的最大偏差为 1.19e-7 rad/s。

| 名义 5 厘米上阶速度 | 父模型带航向反馈 / 20 | 本次带航向反馈 / 20 |
|---|---:|---:|
| 0.32 m/s | 0 | 0 |
| 0.4 m/s | 8 | 5 |
| 0.6 m/s | 16 | 2 |
| 总计 / 60 | 24 | 7 |

本次加入航向反馈后，原协议的 9/60 变为 7/60，横向越界 8 → 4，但姿态终止仍为 19，卡住 12、超时 18。这个对照没有证明走偏是当前主要瓶颈；上阶动作与前进效果仍需检查。平地、2 厘米、3 厘米带反馈均为 60/60。

上一次净空 10500 在相同航向诊断中为 56/60，但它训练了 500 次，本次仅 100 次，而且本次额外改动了转向覆盖与能力保持。因此不能直接把差异归因于某一项约束过强，也不能据此认定只需继续训练。
