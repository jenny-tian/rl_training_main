# Lite3 当前主线与在线学习进入顺序

2026-11-16。用于串起研究方案和后续已批准修订，历史实验及原资格判定保持原样。当前尚未开始新版 EA-LPL 的正式在线学习。

## 研究问题

先掌握六类基础地形，再在更难或新地形上通过交互尝试更新小型适配器，证明更新带来独立评估收益，同时保留已经掌握的能力。基础策略固定；小型潜变量经动作基形成有限幅度的关节残差，并经过安全过滤。在线输入继续使用可部署的本体感知和历史信息，不加入仿真地形真值。

当前应继续遵循 [研究方案 v2](lite3-ea-lpl-research-plan-v2-20261109.md) 的目标筛选、逐地形 Frozen/Updated 主结果、原技能保持、跨地形持续积累顺序。旧 v1 的单地形 P2 已被替代，不能恢复旧方案并称为新版在线学习。

## 何时开始真正的在线更新

1. 本轮已批准部署审计以发现接口问题收尾，不自动增加试验或修复后重跑，也不追加基础 PPO。
2. 下一阶段建议直接回到在线验证准备：锁定当前基线与接口，在 6/7/8 cm 台阶和新地形候选上筛选难度，重新确认残差动作基在当前模型上的改进空间。这个阶段仍冻结模型，防止把纯探索或挑选固定码当作学习收益。
3. 有确认的改进空间后，下一个阶段即启动真正的适配器更新小试和 Frozen/Updated 配对对照。基础 actor 保持冻结；两组使用相同初始适配器、起点序列、探索噪声和预算，只改变是否更新适配器。训练中的偶然通过要在独立起点、冻结快照中复现。
4. 测量六类基础地形保持与已知短板是否加重。逐地形更新得到有效收益后，才扩展到同一适配器跨地形持续积累，并检查遗忘。

因此，从本轮结束算起，下一轮是在线目标/接口与改进空间验证，再下一轮才开始参数更新。各轮仍按用户要求先汇报再获批准。不会把转向完全修好、所有地形 100% 成功或完整实机部署作为新增默认条件；安全和数据有效性检查仍保留。

本次只承诺这个工作顺序，不给尚未打通多回合在线入口的虚假完成日期。旧方案中的日期已过期；120 会话、2万/6万步等为旧设计参考，不能直接当作当前获批预算。具体更新频率和交互预算在目标确认后登记，明确区分 Isaac 20 ms 与 MuJoCo 12 ms 的控制步。

## 收益如何判定

至少包含无残差基础策略、零初始化且冻结的适配器、同初始化在线更新的适配器。保留最佳固定码作为能力上限诊断，不把预先挑好的码放进 Updated 初态。学习结果按独立会话统计，报告完成率、进度、姿态失败、交互量和保持能力；不能把每个控制步当成独立样本。

先检验普通潜变量学习，再根据当前模型的执行响应诊断决定是否加入 EA。EA 指依据残差实际执行效果调整探索分布；若过滤/执行响应没有相应差异，就不能为了使用算法名称强行声称 EA 有收益。C1-a 为回合级码，C1-b 为随状态选码；后者才适合跨地形持续积累。
