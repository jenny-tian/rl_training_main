## 4. 学到的参数

- 每个会话在三个快照上是 19、38、57 次更新。
- 学出来的主要是起伏特征那一列，相当于箱体区的固定码：40000 步时均值是（前腿 +1.48，后腿 −0.94），60000 步时（+1.60，−1.33）。另外三列的均值在 ±0.6 以内。
- 40000 步时 60 个会话里 53% 学到前腿正、后腿负，17% 前腿没学出来；C1-a 改进版同一时刻是 97% 和 0%。参数从 2 个增加到 8 个、探索标准差从 1.0 降到 0.7，学得慢一些，这是增益略低的原因。
- 训练回合的成功率（带探索，按时间三段）：Updated 56% → 68% → 72%，Frozen 41% 到 44%。

## 6. 局限

- 适配器用了仿真里的真实地面高度，没有加高度噪声。
- 学到的内容本质上是箱体区固定码加平地关闭；另外三个台阶特征在箱体上没有起作用。
- 姿态终止的扣分是 3，与 C1-a 的回报不同；判定条件没有改。
- 结果只对 B10200 和仿真成立。
