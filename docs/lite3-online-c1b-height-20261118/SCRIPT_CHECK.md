## 3. 读数

- **局部性只成立一部分。** 只在顶部加码消除了顶部约四分之一的卡住和超时（44 → 33），全程加码消除了约六成（44 → 17）。码要在到达顶部之前就起作用，才能得到大部分收益。训练前按分段比例估算的 +24 偏高。
- **只在顶部加码不增加姿态终止**（5 → 3），这一点与估算一致。
- **在台阶中途把码打开代价很大。** D 组的 20 回姿态终止里有 16 回发生在 x = 1.0 到 2.25 m，即码刚打开之后；抽查的 4 回都是码升到 0.9 后的 30 到 40 步内机身侧倾并后退。B 组从接近台阶时就带着码，这一段只有 5 回。
- **含义。** 在这套动作基和这四个特征下，状态条件的码在上阶能达到的上限大约是 C 组的水平（+9，区间包含 0）。学习器的结果不会高于手工设定的最好值，所以上阶通过五项判定的可能性很低。
