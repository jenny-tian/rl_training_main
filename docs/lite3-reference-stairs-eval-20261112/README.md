# Lite3 参考模型与六类地形模型的台阶对比

本阶段已完成用户批准的冻结策略对比，共计 1080 个正式回合。没有更新任何模型权重，没有修改参考训练或部署项目，没有连接实机。

结果显示：本次从头训练的策略能在平地前进，在部署名义参数下也能完成多数中速下台阶测试，但尚未学会可靠上台阶。参考 ONNX 的部分样本能爬上数级台阶，说明用户观察到的上台阶能力有依据；在本次固定测试条件下，它同样没有完整通过六级楼梯。该结论仅适用于本地这个模型、当前 MuJoCo 资产及本报告的测试协议，不能推断所有历史部署表现。

## 训练阶段结果

训练于 2026-11-12 10:19 正常结束，10000 次 PPO 更新，983040000 次交互，耗时 53180.7 秒。最终检查点能够以 `weights_only=True` 加载，68 个张量全部有限，Adam 更新步数为 200000，文件 SHA256 与训练报告一致。

最终模型 SHA256：`5cf4c1160b6f5b7b5102844526b26f3886c27562d98ea9558e3fa09da504f5a1`。

第 9001～10000 次更新期间，127918 个结束回合中有 43933 个姿态异常终止，实际计数比例 34.3447%。最后 50 轮平均奖励 10.914，回合时长 15.18 秒，平均地形等级 2.968。平均地形等级不能用于判断单独的台阶能力。

## 对比协议

- 三个模型：部署项目 `policy/ppo/policy.onnx`、`model_8000.pt`、`model_updates_10000.pt`。中间模型名称从零编号，实际已经完成 8001 次更新，报告标为 `update8001`。
- 策略结构均为 45→512→256→128→12，ELU。关节顺序 FL/FR/HL/HR，各腿 HipX/HipY/Knee；默认位置 `(0,-0.65,1.3)`，动作缩放 `(0.125,0.25,0.25)`，PD 名义值 30/1。
- 参考模型使用原始 ONNX Runtime CPU 推理，其他模型直接加载 actor 权重，均不采样动作，不加入观测噪声，不训练。
- 使用部署项目的 MuJoCo Lite3 机器人、地板和原始 `stair.xml`，每级 10 厘米，前五级踏面 30 厘米，第六级为落脚平台，总高 60 厘米。去除远处与楼梯测试无关的场景对象。碰撞几何通过编译后的坐标核验。
- 每个模型、每套控制参数、每个方向、每档速度，20 个完全相同的起点。小范围扰动为纵向 ±5 厘米、横向 ±10 厘米、朝向 ±0.03 弧度。固定种子 `20261112 + repeat`，策略启动前用相同 PD 稳定站立 1 秒。实际初始状态逐组 SHA256 一致。
- 上下台阶速度均为 0.2、0.4、0.6、0.8 m/s；侧向和转向指令为零。开始后先零指令 0.5 秒，再用 0.5 秒增加到目标速度。每回合最长 25 秒。
- 另有每模型、每参数组合 20 个 0.4 m/s 平地对照。总计 `3 × 2 × (4 × 2 + 1) × 20 = 1080` 回合。

| 控制参数组 | 策略周期 | 关节扭矩上限 |
|---|---|---|
| deployment | 理想同步 12 ms | 全部 30 Nm |
| training_nominal | 20 ms | 髋关节 24 Nm，膝关节 36 Nm |

两组都使用 1 ms MuJoCo 物理步长、同一机器人和名义 PD。第二组只替换周期和扭矩上限，不复现 Isaac Lab 求解器、随机化、执行延迟或全部电机模型；因此不能把第二组称作原训练环境测试。第一组复现理想同步节拍，没有运行 C++ UDP 线程，其实际丢帧与调度抖动也不包含在本测试中。两项参数同时改变，只能判断组合敏感性，不能独立归因。

成功要求四只脚全部越过末级边沿、机身越过安全余量、机身离目标平台高度在 0.18～0.55 米，几何条件连续保持 0.25 秒，并在结束采样时至少两脚支撑、躯干未触地。正常摆腿不会清除已经保持的几何时间。

失败采用参考训练的重力投影阈值，每 10 ms 检查一次；部署的横滚 30°/俯仰 45°限制另行记录，没有放宽原始姿态阈值。25 秒后最后 5 秒前进不足 0.15 米记为卡住，其余未完成记为超时。离开横向 ±2.5 米范围单列。非有限动作单列为 `policy_numerical_failure`，保留在分母中。低失败率不等于成功，卡住不能算通过。

## 正式结果

所有平地对照均通过：三个模型、两组控制参数，每组 20/20，共 120/120。

部署参数下的完整下楼通过数：

| 指令速度 | 参考 ONNX | 8001 次更新 | 10000 次更新 |
|---|---:|---:|---:|
| 0.2 m/s | 0/20 | 0/20 | 0/20 |
| 0.4 m/s | 19/20 | 19/20 | 20/20 |
| 0.6 m/s | 18/20 | 20/20 | 20/20 |
| 0.8 m/s | 11/20 | 15/20 | 19/20 |
| 四档合计 | 48/80 | 54/80 | 59/80 |

在两套参数和全部四档速度下，三个模型的完整上楼通过数均为 0/80。进一步区分失败表现：

| 部署参数下的上楼结果 | 参考 ONNX | 8001 次更新 | 10000 次更新 |
|---|---:|---:|---:|
| 姿态异常 | 48 | 0 | 15 |
| 卡住 | 21 | 80 | 64 |
| 超时未通过 | 1 | 0 | 1 |
| 非有限策略输出 | 10 | 0 | 0 |
| 至少四脚越过第一级的样本 | 8 | 0 | 0 |
| 最多四脚连续越过的级数 | 4 | 0 | 0 |

部分级数是轨迹诊断：四脚越过对应立面且高于相应踏面，身体高度与倾角满足条件至少 0.1 秒。它不等于整段通过，也不要求每一级停稳。参考模型有爬台阶动作，完整六级可靠性仍不足。不能只用两者的 0/80 总通过率掩盖这个行为差别。

采用训练名义周期/扭矩组合后，三个模型的下楼合计通过数分别为 34/80、23/80、21/80；上楼仍为零。控制参数对下楼影响明显，对当前两个新模型的上楼瓶颈没有形成解决。0.2 m/s 下三者普遍不愿持续下楼；参考训练的命令采样将模长不大于 0.2 的平面速度设为零，这使边界速度值得专门诊断，但本轮没有做因果实验，不能据此确认原因。

0.4 m/s 部署参数下，新模型卡在第一级时，前脚位置接近 `x=1.13 m`，立面位于 `x=1.15 m`；脚球半径为 0.022 m。5 秒之后、仍在第一级前的采样中，最终模型两只前脚中心高度的 95 分位约为 0.023/0.024 米。视频与轨迹一致，说明前脚主要抵住立面，没有抬高越过。此组所有新模型动作绝对值低于 6，排除了本组动作裁剪差异作为直接解释。

以上错误率与成功率是这组固定条件下的经验比例，每格仅 20 个起点，不能当作实机可靠性或全部六类地形的通过率。速度误差只统计该回合结束前的有效数据，失败模型早停可能使误差看起来较小，不能单独排序策略能力。
