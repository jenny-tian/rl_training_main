## 具体工作

1. **奖励时域与失败反馈。** 按训练会话、完整回合和宏动作位置分析当前折扣回报，区分起步、上阶推进、横移和终止扣分的贡献。对照当前 gamma=0.99 与仅用于离线分析的 0.995、0.999，分别对应约 2、4、20 秒的折扣时间尺度；报告成功、横向越界、卡住和姿态失败是否得到可区分的评分。固定原每步评分，不同时搜索惩罚系数或成功奖励。
2. **单回合更新方向。** 从保存初态和原更新日志恢复各回合更新前参数，在相同记录样本上比较上述三个折扣设置产生的单次梯度方向、范数和终止贡献。每个候选都从该回合真实的旧参数计算，不把改变参数后继续复用旧动作的累计结果冒充在线训练，也不做多轮拟合。会话是统计单位，逐步样本不作为独立重复。
3. **残差执行与状态信息。** 分会话和失败类型统计码、请求残差、执行残差、暂停/限幅及实际关节目标修正；分析 8 个现有特征在失败前是否已有可观察变化。需要地形几何定位阶段时只用于离线标注，明确标为仿真诊断信息，不加入适配器输入。不能仅凭总体均值较小就放大安全幅度。
4. **形成单变量结论。** 若有明确证据支持修改折扣时间尺度，优先提出仅改这一项的小试，保持基础策略、18 参数适配器、动作基、学习率和安全边界不变；若证据不足，明确保留不确定性或提出更换假设，不直接加训练次数。任何新仿真试验都另行列出预算、配对起点、评价和停止条件，再请求批准。
