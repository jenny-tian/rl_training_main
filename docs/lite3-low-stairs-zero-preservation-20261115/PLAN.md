# 动作保持系数归零的单项对照

用户已批准上一阶段提出的方案。本阶段从同一父模型 10000 开始，相对组合试验只将动作保持系数 0.5 改为 0。完成后详细汇报，等待下一阶段确认。

## 固定范围

- GPU 1、4096 环境、种子 42。恢复父模型 actor、critic、Adam 及课程总等级分布；旧父模型每个环境的课程等级按原迁移规则重建，物理与 RNG 重新初始化，不声称逐帧连续。
- 原六类低台阶地形、持续净空、纯转向短摆脚奖励修正、持续左右转命令覆盖、原 PPO 主参数和网络保持一致。
- 复用独立种子 20261116 的原训练样本库，不重新采集、不加入正式验收轨迹。辅助损失仍按原路径每个小批次计算、更新采样游标并保存状态，只将系数设为 0。
- 先运行 CPU 检查及 4096 环境 × 64 控制步的零更新集成检查。检查未加权损失非零、加权损失与梯度为零、分布缓存、父模型恢复、样本游标、课程、命令覆盖和重置清理。
- 正式训练固定最多 100 次 PPO 更新，24 步/次、20 个 Adam 步/次，共 9,830,400 次环境交互、2000 个 Adam 步；保存 0、50、100 检查点。非有限值、仿真错误、恢复或预算核验失败立即停止，不自动重启。
- 独立脚本和目录；不改历史训练、奖励、恢复和评估源文件。新入口禁止阶段 2。agent 的 max_iterations 元数据由 200 改为 100，环境和优化超参数进行完整相等检查。
- GPU 启动门槛：训练/集成空闲至少 12288 MiB；评估至少 10240 MiB。不停止其他项目。

## 冻结验证

最终 10100 检查点执行 1600 回合原协议：名义和训练随机化转向各 320；两种物理设置的上阶、下阶各 240。另执行名义上阶航向反馈 240 回合。每条件 20 个起点，台阶 0/2/3/5 厘米，速度 0.32/0.4/0.6 m/s。

使用确定性均值动作、统一参考奖励计分、第一回合、重置前轨迹，核验初始数组和配置一致。航向反馈仍为世界 +x、增益 0.5、限幅 0.8 rad/s，无横向位置反馈；诊断结果单列。

主要比较对象是组合 10100；同时保留父模型 10000 与净空单项 10100。净空单项 10100 没有下阶结果，不补造或借用。

## 决策规则

沿用此前能力筛查：名义 5 厘米上阶三档速度至少 1/20、5/20、14/20；其他名义上/下阶和平地通过数不得低于父模型，姿态终止不得增加。全部转向时间窗的配对 MAE 相对恶化超过 10%、缺失完整时间窗或新增配对姿态失败，均不通过；随机化条件的分组退化单独列出并要求审查。另报告原组合试验中带 0.01 rad/s 绝对误差门槛的 4–8 秒筛查，避免将很小误差的相对变化混为严重退化。

即使上阶改善，出现站立或转向明显退化也不提升为基线。一次单种子对照只能定位本次设置中的影响，不证明广泛泛化或部署能力。无论验证结果如何，均不延长训练，不部署。
