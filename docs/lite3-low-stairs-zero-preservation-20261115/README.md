# 动作保持系数归零：100 次更新对照结果

本阶段已完成，训练没有延长。5 厘米上阶明显改善，但整体能力筛查未通过，当前检查点保留为上阶候选，不替换父模型，也不部署。

相对上一轮组合试验，仅将动作保持系数从 0.5 改为 0，名义 5 厘米完整通过从 9/60 提高到 49/60，带航向反馈从 7/60 提高到 58/60。这支持动作保持约束是本次设置中限制上阶学习的重要因素。高速左转仍比父模型差，下阶存在走偏，且新增一个随机化起步失败；撤去约束没有同时解决所有能力问题。

## 上阶改善与动作约束的关系

原辅助损失在五类真实父模型观测上，按关节动作缩放计算目标偏移，除以 0.1 rad 后取平方，各组等权，再乘 0.5，接入同一次 PPO 反向传播和梯度裁剪。它约束的是共享 actor 参数，不能因为样本库没有专门惩罚台阶摆脚，就认定不会影响上阶动作。

本次只撤去该损失的加权梯度，原净空、转向修正、命令覆盖均保留。相同 100 次更新便出现上阶通过大幅增加，支持该约束参与了上一轮的上阶退化。它属于本次训练目标之间的取舍，未发现本轮存在漏恢复、零系数未生效、单侧命令漏接或预算超限的实现错误。

在未用于训练的旧开发诊断样本上，恢复站姿的关节目标 RMS 偏移由系数 0.5 时约 0.0343 rad 增至本次 0.1688 rad；本次站立、前进、左转、右转组分别为 0.0199、0.0294、0.0367、0.0360 rad。这说明撤去约束后动作变化增大，但单步偏移不能直接解释连续行为，尤其不能用它断言所有恢复状态都变差。

名义 5 厘米停滞代理出现回合数，按低/中/高速分别由 12/16/9 降至 8/7/6。该代理是过去一秒前进不足 5 cm 且连续满足 0.5 秒，仅统计到阶区域、首次倾斜超过 20°之前，区别于正式回合结束时的卡住判定。

为控制暴露差异，碰阶比较仅使用系数 0.5 与本次都已到阶、都未首次超过 20°倾斜且仍存活的共同时间，按四足总暴露时间计算：

| 速度 | 共同暴露总秒数 | 系数 0.5 碰阶占比 | 本次系数 0 |
|---|---:|---:|---:|
| 0.32 m/s | 82.38 | 14.32% | 11.26% |
| 0.4 m/s | 147.26 | 15.95% | 10.71% |
| 0.6 m/s | 79.90 | 14.58% | 11.68% |

中速平均最高跨阶数同时从 4.10 增至 7.00，完整通过从 3/20 到 20/20。碰阶数据是 20 ms 的几何与足端力代理，不能替代接触流形，也不能单独证明某条奖励的因果作用。

单训练种子、训练轨迹分化及反复使用开发测试限制了结论范围。当前结果不证明系数 0 在所有种子都更好，也不证明已经具备 10 厘米台阶或实机部署能力。
