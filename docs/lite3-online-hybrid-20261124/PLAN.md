# 受阻修正加持续选择（C1-b-RD）

2026-11-24。用户同意按建议的顺序做，这是其中第一项。本文件在训练之前提交。仿真里的每步变化上限用 0.04（用户同意），真机安全限制没有改动。

## 1. 要回答的问题

持续选择（C1-b-D）依赖一个事先在别的地形上学好的参数库。受阻修正（C1-b-R）不需要库，但只学摆动幅度，箱体上差很多。本阶段检验：完全不用参数库，先用受阻信号学摆动幅度，再在几种动作形式之间持续选择，36 次尝试时能否接近有参数库的持续选择。

## 2. 学习器

代码 `ea_lpl/c1b_rd.py`，变体 `h1`。

- **第一个回合**（4 次尝试）：与 C1-b-R 相同，从 0 起按受阻比例修正两个摆动幅度，不加扰动。
- **第一个回合结束后**，用学到的摆动幅度 sf、sr 生成 4 组候选（参数顺序是前腿固定、后腿固定、前腿摆动、后腿摆动，w 空间）：

| 编号 | 参数 | 含义 |
|---|---|---|
| 0 | [0, 0, sf, sr] | 只有摆动 |
| 1 | [0.8, −0.8, sf, sr] | 摆动加固定偏置 |
| 2 | [0.8, −0.8, sf/2, sr/2] | 固定偏置加减半的摆动 |
| 3 | [0, 0, 0, 0] | 全 0 |

- **之后**与 C1-b-D 相同：每组先各试 2 次，再按成功次数抽样分配尝试，平均得分最高的一组是当前参数。
- 固定偏置的方向（前腿缩、后腿伸）和大小 0.8（tanh 后 0.66）来自库里两组箱体参数（0.65 / −0.93 和 0.68 / −0.67）。这是从已有结果里得到的先验，候选的数值不取自任何一组库参数。

## 3. 实验

都在上限 0.04 下，目标是 7 cm 上阶、7 cm 箱体、7.5 cm 上阶、8 cm 箱体，每个 10000 步，在 1250、2500、5000、10000 步存快照并评估（约 4、9、17、36 次尝试）。

| 编号 | 内容 |
|---|---|
| H1 | `h1`：受阻修正加持续选择，10000 步做保持评估 |
| H2 | `r2`：只有受阻修正（上限 0.04 下的 C1-b-R），只做目标评估 |
| 对照 | `d4`：有参数库的持续选择，上限 0.04（[方案](../lite3-online-rate04-20261124/PLAN.md)，已在运行） |

## 4. 判定（训练前登记）

- **主判定**（每个目标分别判定，H1 在 10000 步）：
  1. 对 Frozen 的成功率增益不低于 10 个百分点，且 95% 区间下限大于 0。
  2. 对 H2 同一快照的配对差，95% 区间下限大于 0（加上动作形式的选择比只学摆动幅度好）。
- **与有参数库的比较**（只作描述）：H1 对 `d4` 各快照的配对差。
- 其余三项沿用，在 10000 步判定：姿态终止增加不超过 2 个百分点，各地形族成功率下降不超过 5 个百分点，平地速度误差比不超过 1.10。
- 区间用按会话重采样的自助法，10000 次，种子 0。

## 5. 没有把握的地方

- 上阶上只有摆动的一组本来就接近最好，加上选择可能没有差别，主判定第 2 条在上阶上可能不通过。
- 固定偏置 0.8 只取了一个值；偏置的方向是从箱体的结果里来的，对别的地形族不一定合适。
- 第一个回合占 4 次尝试，之后每组各试 2 次再占 8 次，前 12 次尝试里选择还没有展开。
