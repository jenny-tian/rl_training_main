# 规模检查适配器与 16 环境 G1 运行准备

状态：`cpu_adapters_complete_waiting_for_single_G1_launch_approval`，2026-11-03。

用户批准 CPU 实现和运行准备。本阶段完成稀疏接触采集与独立重建、通用运动和
选择性 reset 观察器、原生指标采样与归一化回合聚合器，以及限定 16 环境 G1 的
监督入口和验收器。本阶段没有启动 Isaac Sim 或 GPU 任务，新增真实交互和 PPO
更新均为 0。生产预算台账、原始 checkpoint 和既有运行归档保持不变。

## 稀疏接触证据

`sparse_contact.py` 在 CPU 上逐帧检查完整配对矩阵的有限性，取 count 非零或 force
任一分量非零的并集。即使 count 为零、force 只有 1e-8 N，也会保存，跨环境非零
同样拒绝。随后检查详细接触范围、重叠、容量饱和、有效接触点有限性和单位法向量，
并核对详细法向力重建、配对合力和 net force，沿用 atol/rtol=1e-4。

证据包括配对索引、count、start、原始详细缓冲索引、法向力、点、法向量、距离及
net force。未使用的 native 槽位不属于有效接触数据，可以是 NaN；零 count 项的
start 规范为零。零配对按隐式零恢复，正负零统一为正零后，对完整 float32 matrix、
uint32 count 和 net 数组分别计算 SHA。独立 CPU 解码器用另一套逐项循环重建，
验证详细点和完整数组 SHA；丢掉很小的 force-only 项也不能靠数值容差通过。

拓扑只保存传感刚体、目标路径和去重后的过滤顺序，支持各传感器不同的目标顺序。
每控制步重新核对解析路径，逐物理子步检查原生维度/容量和场景/backend 生命周期。
无异常时不保存完整稠密矩阵；读取成功后的校验故障保留全部原始缓冲 NPZ。底层 API
读取失败时保存已返回的部分，明确列出可用项，不能把未读到的数据报告为完整。

新采集器独立于已有两/八环境采集器。候选详细接触容量为 16/32/60/120 环境分别
131072/262144/524288/1048576；未取得实测容量或吞吐资格。120 环境完整尺寸测试
实际分配了 2040×2064×3 力矩阵、count/start 和一百万容量详细缓冲，并完成编码、
解码。该用例是 CPU 合成零接触数据，不能据此保证真实 G3 的日志体积或运行速度。
另有用例从上次真实八环境归档读取首个接触帧，在 CPU 上转码后与原矩阵精确一致；
这没有产生任何新物理交互。

## 运动、reset 与指标适配器

`ScaleObserver` 支持 16/32/60/120，逐 5ms 子步保存 17 个刚体的显式 link 位置、
速度、四元数和基座 scanner。当前位置包络越界、扫描归属/缓存年龄、非有限状态
均停止；20ms 预测项保留为任务结束信息，不冒充连续时间安全证明。异常运动状态
写故障记录。选择性 reset 比较紧邻 `_reset_idx` 的全部缓存和 filter/lifecycle
状态，独立回放分配票据并核对 spawn；保存前后原始快照，观察下一物理子步恢复。
直接 reset 不产生训练 transition，恢复首步未出现时保持 pending。

CPU 用例覆盖单行、不连续行、偶数行、全部行，包含最高 env ID；120 环境取得两
个完整 120 票据块。回归验证 reset 改动未选择行会被拒绝，全部临时钩子都恢复。
这些是合成环境结果，不是新规模的 PhysX 运行资格。

指标实现包含：

- 原生批量采样：按 FL/FR/HL/HR 足名映射接触传感器，记录 reset 相对前进/横漂、
  速度误差、姿态代理、足位置/速度/接触力。终止行在 reset 前复制，收集时替换
  reset 后样本，禁止缺失、重复或步骤不连续的数据进入回合聚合。
- 回合聚合：输出上一阶段的 `lite3_source_episode_metrics_v1`，全部 15 条件可直接
  输入已有 Source 选模校验器；包含完整失败回合，负前进量不丢弃。缺少接触分母或
  必需测量时明确拒绝归一化，不把缺失指标补成零。已完成回合不允许再追加或改结果。
- 几何指纹：使用局部网格、逐面 static/dynamic friction/restitution 和几何参数，
  规范顶点/面顺序并保留材料与面的对应关系；几何 seed/state ID 不参与身份判断。
- 物理材料审计：读取实际绑定的 USD physics material 参数，单独保留绑定关系。
  绑定参数不是有效接触摩擦系数的实测值，报告不声称后者已测量。

定义沿用既有诊断：接触力大于 1 N，接触足世界水平速度大于 0.35m/s 计滑移代理；
roll/pitch 使用 projected gravity 分量的 asin，是姿态代理而非完整欧拉角解算。
根速度使用现有生产 `root_lin_vel_b`，足位置/速度使用显式 link API。前足碰撞为
距已审计立面不超过 0.08m、水平力达到 20N 的上升沿；25 个低速控制样本、同踏面
进度跨度不超过 0.05m 计一次卡滞踏面。坡面检查出口过渡，粗糙要求网格峰谷/尺度
审计，摩擦按实际接触足所在区域计分子/分母，区域边界按输入顺序选择首个匹配项。

调用者仍须为真实评估提供对应网格、区域和材料审计 descriptor。本阶段没有实现
完整多回合评估调度，没有校准 20N 检测器或把这些适配器标为 live qualified。
旧 Source 选模阈值、600 transitions/s 门槛和 numeric 运行清单仍保持未批准。

| 项目 | 固定范围 |
|---|---|
| 设备 | GPU0 / cuda:0，可共享，启动前至少 12288 MiB 可用 |
| 场景 | 16 环境、1 行 shared bank、六家族/15 个 L1 条件保留 |
| 入口配置 | SourceTrainingEnvCfg，环境130001、几何30000、sampler131001 |
| 运行量 | 1 个零动作控制步，4 个 5ms 物理子步，16 条只读诊断交互 |
| 策略和优化器 | 不加载策略，不构造 PPO，更新 0，训练数据 0 |
| reset | 不注入超时，不执行直接 reset；意外回合结束拒绝 G1 |
| 原始证据 | 全刚体接触、运动、双 scanner、1 份原生指标样本 |

| 输出 | `/tmp/lite3_source_shared_g1_16env_20261103`，禁止覆盖 |
| 后续 | 不重试、不自动扩容、不继续 G2/G3/G4 或 PPO |

监督器与子进程均在导入仿真前核对独立启动批准、实际远端 SHA、干净工作区、完整
源码/资产、51 项安装依赖和只读预算快照。新增依赖为 NumPy1.26.0 的七个关键
源码/二进制文件，另复用已登记44项。真实运行将记录 GPU 卡级显存/温度/利用率、
计算进程显存、子进程 RSS 和启动/场景构建/首步时间；卡上已有任务不算本次占用。

父进程须独立重建四帧接触证据、检查四帧运动及扫描、碰撞组、零动作、步数、指标
完整性和关闭记录。退出0或成功标记不能单独通过。只清理本次进程组，应用 close
记录为 closing 后正常退出可以接受，但不会声称 Python 层 close 已返回。

G1 只检查这一次启动和首步链路，不要求首步所有环境已经触地，始终保持 ground
positive qualification=false。通过也不授予运动隔离、长时间稳定性、技能、G3/G4
或训练资格。16 条只读诊断交互单独登记，不写 Source PPO 预算；运行前后台账
必须保持一致。当前生产台账仍只有 run1 accepted 的384条诊断、2次真实更新。
