## 需要优先修订的问题

### 0. 阻塞：G0 首个冻结 base 复跑未复现“101 失败”

审核期间按预登记 G0-20260928-base-pair 运行当前 LoRA runner：seed 101、simulation seed 7、同一 base SHA、RockyRoad rough_4cm、2000步预算。
结果为1785步完成，max_x=4.502410411834717 m，updates=0、fell=false、safety_violation=false。
轨迹重算max_x与summary一致，保存671535字节；控制计算耗时p50/p95/p99约3.76/5.06/5.52 ms（含当前worker控制前处理和GPU同步，不等于完整实时循环延迟）。
证据目录：`artifacts/g0_base_pair_20260928/seed-101/`；代码commit：`1113b4e`。

这不证明旧结果错误，也不构成学习收益。当前结果与计划前提不一致，需审查runner动作处理、观测/初始化、地形与物理配置、版本和GPU差异，并在固定条件下复测。
其余调试种子的预登记基线仍继续采集以定位差异；在原因明确前不把101视为可靠的base失败样例，也不依照旧失败池启动G1学习效果判定。

### 1. 高：critic 失败的因果判断过强，EV 口径不独立

计划 2.2 的“critic 从未拟合回报”“更新方向接近随机”不是现有指标能证明的事实。
`ppo_online.py:OnlinePPOUpdater.update` 用采样时的 old_values 与 `compute_returns(gamma, gae_lambda)` 的目标计算 EV；目标仍包含当前 critic 的 bootstrap。这个更新前、短窗口、移动目标 EV 不等于留出完整回合的 MC 拟合质量。

建议：先重建独立回报，按完整回合划分训练/验证，固定采样策略、噪声日程和扰动种子。
同时报告 EV、归一化 RMSE、偏置、目标方差、位置/阶段分组误差，以及“常数/仅时间”基线。
EV>0.3 只能作为预登记工程门槛；不能把“EV 更高”单独当作策略改进证据。
同一个确定性初态重复采样不构成新的独立验证回合；需要独立噪声/扰动。

### 2. 高：λ=1 不自动等于 MC；改成剩余距离可能改变优化目标

当前 `ppo_rollout.py:compute_gae` 在截断边界仍使用 next_value。只把 λ 改为 1，在 256 步截断 block 上得到的是带 bootstrap 的多步目标，不是完整 MC。
必须明确：完整失败/成功回合、任务 deadline、采样预算截断分别如何计算尾项。完整终止回合的 discounted return 可以作为 MC 目标；没有终局信息的截断回合需要标记为 censored 或按登记规则 bootstrap，不能冒充 MC。

γ=0.99、λ=0.95 时，GAE 递推系数是 0.9405：100 步后约 0.00217，200 步后约 4.70e-6。
仅引用 0.99^200≈0.134 解释 actor 信号传播不完整；回报折扣、GAE 递推和 critic 误差必须分开审计。

先使用同一奖励下的固定线性缩放/标准化并正确还原价值尺度。
任意裁剪回报、只用剩余距离替换原回报、忽略吸收成功奖励会改变策略目标；如果试验，应登记为新奖励臂而不是“仅修 critic”。
复用 base critic 还必须核对输入字段顺序、归一化和特征权限；48 维相同不代表语义相同。

### 3. 高：G1 门槛存在错误淘汰与跨算法不一致

“残差 RMS≥最终探索 std”不应是必要条件：微小、定向的修正也可能有效，大残差也可能破坏步态。
保留为诊断，主要门槛改为独立冻结执行改善、平地保持与预登记失败限制。
SAC 不能直接沿用 V 的 EV 门槛：soft Q 的目标含熵项，和纯奖励 MC 回报不同。
只看 Q 与 MC 的相关系数也不能发现整体尺度/偏置错误，应先统一 soft return 或评估 reward-only value，再报告校准误差与相关性。
D4“所有比较前 LoRA 必须通过”与 D9/F1“各方法独立晋级”冲突，建议采用后者。

### 4. 高：四臂的预算和评估口径尚不公平

20 个回合可能因早摔与成功产生完全不同的步数，不能同时称作相同交互预算。
建议登记固定环境 transition 上限 B（例如最多 40,000 步，数值在启动前锁定），所有用于选择或更新候选的目标地形采样都计入，包括 critic 预热、BO/CMA-ES 评估、快照分支和候选晋升探针。
纯终点评测使用独立、各臂相同的预算，不回流训练。另报告回合数、reset 次数、墙钟时间与梯度更新次数。
独立 session 均从同一个 base/固定初始化开始，禁止把上一地形的学习器状态带入下一地形。

P1 保留为统一主要终点。P2 对梯度臂用训练回合，对 D 臂改用评估回合，已经不是同一个终点。
建议 P2 降为训练过程指标；所有臂最终统一做无噪声、无更新、同一批扰动起点的冻结评测。
探索对照按探索机制分别配对；修改成相关噪声后不能只沿用原白噪声对照。

### 5. 高：M1/M2 的证伪标准和创新命名需收紧

M1 的 R²>0.1 只能说明执行残差可预测。安全投影本身是状态相关映射，即使没有任务收益也可能产生可预测性；R²低也可能来自多模态/缺少历史，不能直接推出“成功只是运气”。
增加同噪声预算下的成功/失败/无更新样本对照，按回合而不是时间步拆分，并以监督后独立闭环冻结收益作为晋级依据。
执行动作可以作为模仿目标，但必须保存前一执行残差、投影状态/原因等历史，并检验经过安全器再次执行时的效果，不能直接套用 PPO 请求动作的似然契约。
当前 Gaussian base 上建议称为“成功轨迹自模仿/动作残差蒸馏”，不要称为已实现 FlowDAgger 或专家 DAgger。

M2 的提升必须使用相对位移 Δx=max_x−initial_x。101 从 −3.5 m 到 0.65 m 已前进 4.15 m，30% 应相对此位移计算，不能用有符号世界坐标比例。
应锁定基函数、步态相位来源、参数单位/范围、零点等价与平地保护，再做网格。
50 个格点的最优结果存在选择偏差，需要独立扰动复测；粗网格没有收益只是否定所试范围，不能否定所有低维 steering。
平地动作锚点 MSE 不能替代实际平地 rollout 的保持评测。

### 6. 高：快照分支拥有额外权限，根位置误差不足以验收

M3 必须包含机器人 root/joint 状态、控制器上一动作、限速器/安全状态、历史缓存、命令与计时器、接触/传感器状态、RNG，以及 PhysX 隐状态的可恢复性说明。
除了 75 步根位置误差，还要报告关节状态、姿态、接触、奖励和终止事件一致性，并测试自由运动、持续接触和碰撞附近快照。
若接触缓存不能可靠恢复，M3 退出该轮，不用手工篡改状态凑阈值。
即使分支步数计入预算，可回溯到过去状态仍是额外仿真权限。M3 应单列为仿真特权上界/辅助臂，不能作为与不可回溯在线方法完全同权限的胜者。

### 7. 中：统计与封存规则需补齐

5 次中成功 4 次可以是操作定义，但不能证明真实成功概率≥80%。（4/5 的精确 95% 区间约为 0.28–0.99。）
F/S 池需明确使用确定性还是扰动 base 表现筛选、混合成功实例如何处理；筛选起点与终点评测起点分离，各方法与 base 使用同一评测扰动。
结果限定为“base 失败池上的条件适应能力”，不能外推到所有随机地形。
只有边际成功率不足以给出精确 McNemar 功效，还需要两种方向的不一致概率；计划中的功效数值缺少假设，不宜作为样本量依据。
P2 的比例只有六个取值，Wilcoxon 有大量 ties/zeros；建议预登记适合配对离散数据的精确置换或层级区间，并明确多个臂/主要终点的多重比较处理。

封存时可以按预先固定的算法在新地形内在线更新，但每个 session 后重置学习器；适应数据、晋升探针与最终冻结评测必须分开。
从哈希派生种子不等于防止挑选：任何文件改动都会改变种子。冻结协议后禁止重写/重抽，并保存已用种子全集和守卫测试。
S1 允许丢失≤1/10，而 F4 到≥3/10 才触发，2/10 未定义；S2 的相对5%在 base误差接近0时不稳定，需登记绝对容差和分母处理。

### 8. 中：证据记录有一处事实错误，开发范围偏大

“没有逐步轨迹”不准确：实际读取 `ablation_proprio_20260922/episodes/episode-0001/latest.pt`，其中 `rows` 有 1438 条，包含 reward、old_value、base_x/y、done、learning_terminated/truncated、投影误差等。
旧数据能先用于回报与价值诊断；缺少的是完整观测、请求/执行动作向量等自模仿必需字段。
诊断日志可以压缩观测/动作，但奖励、位置、时间建议保留 float32/64，避免量化误差污染回报和位置对齐；要保存终止前末帧，不能误记 reset 后状态。

M0–M4 同时开发会消耗大量工程时间。推荐近期只做：旧数据诊断＋完整轨迹记录、LoRA critic 最小修复、SAC 目标域预热诊断、M2 两维 headroom。M1 有有效轨迹后再做，M3 作为有时间上限的可选实验，M4 延后。
“两臂都失败”的 F2 表述需更新为“所有已通过 G1 并进入 G3 的适应臂都未达标”。

## 对创新性的判断

LoRA、LayerNorm、n-step、MC 预热、低维搜索和风险门控均不能单独主张原创。
受控比较和负结果可以构成实证贡献，但目前“这些条件组合未见论文”的调研表述不足以证明算法创新。
若学校要求算法创新，应在 G1 之后只选择一个得到机制证据支持的改进，明确可实现定义与必要消融；不能提前保证会达到目标。
