# 下一阶段提案：定位平地与转向退化

状态：待用户确认，尚未执行。本阶段只做冻结策略诊断和修复方案登记，不执行新的 PPO 更新，不进入阶段二。

## 要回答的问题

当前两个起点都能学习新台阶，但第一段检查已出现原 Flat 保持失败。需要区分：持续纯转向是否也退化、原 Flat 的航向误差收敛/减速是否退化、平移和侧移是否同时受影响，以及分块平地与原 Flat 的运行分布是否存在关键差异。增加纯转向样本的事实不能直接证明样本足够，也不能证明当前转向指令覆盖了原 Flat 的所有行为。

## 具体执行

1. 固定比较原平地 1998、原地形 3497，以及本段四个 100 次检查点；所有策略冻结。保留现有 Q4 指标，不修改安全阈值。
2. 分别在原 Flat 与 B2 平地列记录相同定义的 vx/vy/wz 指令、实际速度、偏航误差、回合结束原因、接触身体部位、动作变化及奖励分项。按环境组单独汇总，避免六类地形整体平均掩盖转向退化。
3. 用配对初始状态区分左/右持续转向、减速到站立、正负角速度切换，以及原 Flat 的航向收敛命令。每种条件至少 32 个首回合，明确控制周期、命令变化时刻和排除重置后的测量规则。
4. 核对源码及实际配置：命令重采样、航向控制掩码、随机推力/摩擦、平地身高奖励参考、全向组的有效交互量。发现确定的实现错误时，先整理可复现证据和最小修复补丁，交付下一轮训练前的审查材料。
5. 根据诊断只登记一个主要干预，明确加载方式、学习率/保持约束是否改变、两个种子的预算和停止规则。不能同时调整多个奖励、采样比例和优化器后再声称定位了单一原因。

## 交付与边界

交付按指令类别的误差表、真实速度响应曲线、失败片段和对应接触记录、实现核对结果，以及下一轮修复试训的具体配置与预算。说明哪些结论有直接证据，哪些仍是候选解释。诊断结束后详细汇报，由用户确认后再执行修复训练。

当前观察不要求从零重训，也不支持直接把未通过 Q4 的新检查点选为最终基础策略。后续起点选择应综合本轮两个种子的结果与诊断证据，继续使用隔离的原 L1/L2 和原 Flat 作为最终资格标准。
