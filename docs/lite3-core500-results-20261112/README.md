## 固定评估与解释范围

冻结新策略执行 1600 个正式回合：转向 640、上台阶 480、下台阶 480。上下台阶各含 120 个平地对照回合。评估使用确定性均值动作，名义参数和训练随机化分开统计。

转向协议包括左右 0.2/0.5/0.8 rad/s、停止、反向、90°目标航向、前进转弯及平地站立/前进。每类每种条件 20 个起点；完整时间窗口和全部起点的失败数分别统计。

台阶协议使用原生方形台阶，固定 5/10/15 cm、0.32/0.4/0.6 m/s，每个组合 20 个起点。四脚越过第一级与整段完成分别报告。下台阶要求落到低踏面并有支撑，避免将飞跃边缘当成通过。

冻结基线为原最终 10000 次更新模型。已有转向和上台阶数据仅在初始状态数组完全一致时复用；否则在本次 GPU 1 上重跑冻结基线。下台阶补齐同协议冻结基线，不训练原奖励模型。

冻结评估沿用同一套原奖励计算，仅用于统一记录；奖励不会更新冻结策略。判定改善依据实际动作、速度、航向和跨阶结果，不能将评估中的旧站立惩罚误读为核心训练修正未生效，也不能直接比较修改前后训练总奖励。

新检查点必须同时提供路径、模型标签和 SHA256，禁止用历史标签冒充新模型。视频固定选择原地先右后左的起点 0，以及 10 cm、0.4 m/s 上台阶起点 0；录制重放需与对应正式运行的全部轨迹核对。

本实验只有一个种子和 500 次新增更新，用于筛选方向；不将一次结果解释为已证明某个奖励项的唯一因果贡献。
