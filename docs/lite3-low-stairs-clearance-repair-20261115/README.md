# 台阶抬脚奖励修复与冻结验证

本阶段落实用户批准的第二项修复：解决净空奖励低抬脚高度得分相同，以及停脚、碰阶后计分消失的问题。代码与冻结验证完成，PPO 更新为 0。当前模型的上阶能力没有因此改变，下一阶段试训等待用户确认。

## 修复范围

新增 [纯张量规则与射线采样](../../scripts/tools/reference_low_stairs_clearance.py)、[单项配置适配](../../scripts/tools/reference_low_stairs_clearance_cfg.py)、[冻结验证](../../scripts/tools/reference_low_stairs_clearance_validate.py) 和 [证据核验](../../scripts/tools/reference_low_stairs_clearance_verify.py)。只替换 `stair_clearance`，配置权重仍为 −1。

地形维持六类分块、2–5 cm 台阶和原生课程。actor 仍为 45 维本体观测，critic 仍为 393 维；PPO、物理随机化、速度命令、转向奖励和其他奖励保持一致。没有叠加旧 A 的碰阶惩罚，也没有启用 B 的转向修改。原训练及上一阶段恢复源码均保持原哈希，参考项目仍只读。

### 连续区分净空不足

原公式对高度不足量截断后平方。5 cm 台阶前，脚底从地面抬到 2.5 cm 都得到相同惩罚；同时再乘当前前向脚速与无接触条件。

新公式为 `d² / (0.05² + d²)`，其中 `d = max(台阶目标高度 + 0.025 − 脚底高度, 0)`。结果在 0–1 范围内，有限的正高度不足量没有硬截断平台。目标以上为零，不提供额外的高抬脚正奖励。

以下是假设同一只脚处于有效摆脚过程、台阶高 5 cm 时的逐足代价；原公式另假设前向脚速 0.5 m/s、无接触。实际奖励为四脚代价平均后乘 −1，管理器再乘控制周期。

| 脚底离地高度 | 原代价 | 新代价 |
|---|---:|---:|
| 0 cm | 1.000 | 0.692 |
| 1 cm | 1.000 | 0.628 |
| 2 cm | 1.000 | 0.548 |
| 2.5 cm | 1.000 | 0.500 |
| 3 cm | 0.810 | 0.448 |
| 5 cm | 0.250 | 0.200 |
| 7.5 cm 及以上 | 0 | 0 |

沿用原来的 2.5 cm 余量。因此 5 cm 台阶的有效摆脚目标是脚底达到 7.5 cm，正常支撑时不要求维持这个高度。新曲线改变了惩罚幅值和触发时长，权重相同不代表所有轨迹的总惩罚相同。

### 保留摆脚目标，区分碰阶与支撑

- 仍在台阶列、平面速度命令大于 0.1 m/s、姿态满足原净空条件时才启用。台阶识别和脚底正下方地面高度复用原来的五条垂直射线。
- 脚离开合法支撑且前方存在至少 8 mm 高差时，记录这一摆脚的目标台阶高度。此后停脚、脚向后运动或短时不再看到前方高差，不会自行清除目标。
- 足球中心及下半部增加三条水平射线，结合反向接触合力识别邻近台阶立面。各射线使用对应球截面半径加 8 mm 容差。中心射线错过边缘时，下方射线仍可覆盖球底碰阶。
- 合法支撑立即免罚；连续支撑 40 ms 后结束本次目标。碰阶接触不计作合法支撑。一帧支撑后又抬脚时保留原目标，避免短暂接触清除状态。
- 停止平移、进入纯转向、离开台阶任务、姿态超限或命令方向偏离记录方向超过约 60°时取消旧目标；新的方向如满足条件可以建立新目标。
- 四条腿使用完全相同的公式、阈值和状态机。全局及局部重置清空对应环境的状态和采样缓存，同一步重复读取不会重复推进落地计时。

净空状态只用于离线训练奖励，不进入 actor，也不提供部署时可用的地形信息。续训从新回合开始，清空摆脚状态；没有宣称恢复中断回合的摆脚历史。

## 验证结果

89 项 CPU 检查通过。新增检查覆盖低高度可区分、2/3/5 cm 高度范围、世界高度平移、四腿置换、世界方向旋转、停脚、碰阶、低处及高处正常落地、短接触、命令变化、局部重置、同一步缓存、射线数组形状，以及验证入口拒绝训练参数。既有净空、碰阶、课程恢复和父模型检查也通过。

GPU 1 分别运行旧净空与新净空两个独立进程，各为 4096 环境 × 360 控制步，共 2,949,120 个环境步。每个环境采样 7.2 秒，保持原训练地形、随机化、命令和课程。两次通过运行总耗时约 316 秒；监测到的 GPU 1 总显存峰值为 13858 MiB，包含其他进程。两次均通过上一阶段的恢复组件加载原低台阶 10000 次父模型；不从发生退化的 A500 继续。

旧模型逐环境课程没有保存，两次均采用同一确定性迁移：精确恢复已记录的全局等级数量，重新分配逐环境等级。初始平均等级 5.763916015625，整个验证的奖励倍率均为 1。这仍不等于原历史逐环境状态的恢复。

最终验收要求：

- 两次完整物理轨迹与全部 actor/critic 观测的摘要完全相同；所有其他奖励的摘要完全相同。
- 同一轨迹上计算的新旧净空代价分别完全相同，保存的 234 个环境逐字段轨迹也完全相同。
- 实际奖励管理器计分与独立核对一致，误差小于 1e-6；无非有限观测或奖励。
- 非台阶、纯转向、站立不触发新净空项；真实支撑免罚；自然回合重置和显式局部重置正常。
- actor、critic、Adam 与学习率不变，父检查点文件哈希不变，PPO 更新为 0。

## 仍需训练验证的限制

1. 模型参数没有改变，本阶段没有新的上阶成功率。360 步冻结采样用于集成检查，不替代完整上下阶或转向验收。
2. 立面射线加合力仍是接触代理，无法精确还原足球上所有接触点。有限射线间距、球边缘和同帧地面摩擦可能影响判定。
3. 目标在一次摆脚内保持固定；一次跨过多个台阶、特殊命令变化和长时间悬脚的策略选择，仍需观察训练结果。零正向高抬脚奖励不能证明所有取巧行为都已排除。
4. 旧模型的 actor 没有前视地形输入或历史记忆。这项修改提供训练信号，无法保证每一步都提前识别台阶。净空修复和原有前进、落脚奖励需共同形成有效动作。
