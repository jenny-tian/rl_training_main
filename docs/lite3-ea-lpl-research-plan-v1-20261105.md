## 1. 研究目标

在冻结的 Lite3 基础策略上，只训练一个很小的二维潜变量残差适配器，让机器人在基础策略走不过去的地形上，用有限交互在线改进。按计划书分四步验证：

1. C1-a：回合级在线权重更新（Frozen 对 Updated）能否在独立评估中带来收益。
2. C1-a-EA：执行感知探索协方差在 C1-a 中是否有额外收益（有前提条件，见 D8）。
3. C1-b：状态条件的高层策略（每 Δ 步重新选码）能否学到运动历史到行为的映射。
4. C1-b-EA：完整 EA-LPL，执行感知协方差加状态条件更新。

## 3. 关键决定

**D1 基础策略 θ₀ = model_1998 加航向闭环。**
转向指令 = clip(0.5 × wrap(0 − 当前航向), −0.8, 0.8) rad/s，前进指令 0.3 m/s，横向指令 0。航向由 IMU 姿态得到，真机可实现。闭环参数直接取原训练配置，策略在训练中见过这种指令。预期它主要减少航向偏转造成的漂移；横坡上的侧向滑移和上坡速度不足预计仍会失败，这些失败正好作为在线适应的目标。实现时必须同时放开转向指令范围，并关闭纯前进样本槽，否则转向指令会被限幅成 0（Isaac Lab `velocity_command.py:155`）。Source PPO 以后若训练出合格模型，可以替换 θ₀，替换后重做 P0。

**D2 暂停 Source PPO 小步微调路线。** 已有 checkpoint、并行环境、隔离检查、交互账本和审计工具全部保留复用。update1 阶段提出的离线奖励与观测设计方案不执行。

**D3 统计单位是并行的独立 session。** 仿真中一个并行环境运行一个 session（自己的 ψ、随机数和初始状态序列），120 个环境就是 120 个 session。每个 session 的训练预算沿用计划书的 20k 控制步，另做 60k 的延长曲线。统计推断以 session 为单位，不以回合或控制步为单位。

**D4 初始状态扰动，按不同轨迹计数。** x ±0.2 m、y ±0.1 m、yaw ±0.1 rad，按（表种子，命名空间，槽位，回合序号）确定性生成，不消耗仿真的全局随机数。需要配对比较的各组使用相同起点。报告里的完成数都对应不同轨迹。

**D5 目标地形按 P0 规则选择**（第 5 节）。优先一个横向失败条件（横坡）和一个纵向失败条件（上坡或台阶），覆盖 L1 和 L2。

**D6 动作基 V 有三个候选，每列按过滤器上限缩放。**

| 名称 | 第 1 列 | 第 2 列 |
|---|---|---|
| sag | 前腿（FL、FR）HipY −0.10、Knee +0.20 | 后腿（HL、HR）同样的协同 |
| roll | 左腿（FL、HL）HipY −0.10、Knee +0.20 | 右腿（FR、HR）同样的协同 |
| hipx | 四条腿 HipX 同号 +0.12 | HipX 按 FL、FR、HL、HR 为 +、−、+、− 各 0.12 |

HipY 与 Knee 的 −1:2 比例沿用 C0。hipx 的两列张成的平面同时包含左右平移和站宽变化两种模式，不依赖左右腿关节轴的符号约定。残差请求 r = V·tanh(u)，|u| = 2 时约达到上限的 96%。P1 用网格测量每个动作基的改进空间并按规则选一个。不修改安全过滤器上限，除非用户批准（决策点 D-1）。

**D7 C1-a 采用全局码学习。** 每个 session 固定在一个地形条件上，回合开始前能拿到的上下文几乎不变。按计划书 4.1 节的说法，这种情况只能称为全局回合级策略参数学习，所以 C1-a 只学 μψ = b（2 个参数），码从回合第 1 步开始生效并保持到回合结束。状态条件学习交给 C1-b。

**D8 执行响应的两种定义。** 计划书用单次过滤器调用的局部 Jacobian。现有过滤器下，回合开头之后执行残差和请求一致，单步、小 δ 的 Jacobian 基本等于 V，看不到速率限制的影响。P1 同时计算：

- 计划书原定义：单步，δ = 0.05，参考点 u_ref = 0。
- 宏动作定义：Δ = 10 步内执行动作的平均变化，δ = σ0 = 0.6，参考点取保持点 u_ref = u_{k−1}。

后者对应 C1-b 的实际探索尺度和保持时长，作为 EA 是否进入 P5 的判定依据。u_{k−1} 是已经执行的历史动作，不依赖当前 ψ，符合计划书 2.4 节对参考点的要求。

**D9 探针改为离线快照评估。** P2 在训练步 0、5k、10k、20k、40k、60k 保存 ψ，训练结束后在独立起点上冻结评估，评估交互单独计费。计划书第七节的退化触发、候选隔离、原子发布和回滚属于部署配套，推迟到 P6 之后的真机准备。

**D10 数据划分。** Source 15 个条件及其 L2 版本用于开发（P0 到 P5）。rough_4cm（RockyRoad，含 101 和 107）已经用于开发和完整 PPO 训练，只能作开发地形，不能作封存地形，这一点更正计划书 3.2 节。boxes、pyramid_stairs、pyramid_stairs_inv 保留为封存家族，P6 之前不访问。

**D11 执行节奏。** P0 到 P2 一次批准，阶段之间按预登记规则自动衔接，只在第 6 节列出的用户决策点停下。

## 5. 预登记判定规则

以下数值在看到对应数据之前固定，执行中不得修改。

**P0：目标条件选择。** 使用开启航向闭环、带初始扰动的结果（E1p-L1 与 E1p-L2，每条件 8 个环境）。

1. 排除平地。
2. 完成率 > 60% 的排除。
3. 安全终止（摔倒、非足端接触超时等）比例 > 10% 的排除。
4. 完成率为 0 且平均前进距离 < 4 m 的排除。
5. 剩余条件按机制分为横向（名称含 cross_slope）和纵向。排序键：完成率在 [10%, 60%] 的优先；其次完成率与 30% 的差距越小越优先；再次平均前进距离越大越优先。
6. 取最优的横向条件；它的左右镜像条件也满足 1 到 4 时一并取；再取最优的纵向条件。最多 3 个条件。
7. 一个都没有时进入决策点 D-0。

**P1：改进空间与动作基选择。**

- 筛选：每个目标条件、每个动作基、每个码（u 的两个分量各取 −2、−1、0、1、2，共 24 个非零码加 1 个零码），各用同一组 8 个起点。
- 确认：每个条件、每个动作基，取筛选中完成数比零码至少多 2 个的码，按（完成数，平均前进距离）排序取前 3 个，在 16 个新起点上与零码配对复测。
- 确认通过：码的完成数比零码至少多 4 个（16 个中），且安全终止数不超过零码加 1。
- 动作基得分 = 各目标条件上确认通过的最大收益（(码完成数 − 零码完成数)/16）之和；选得分最高的动作基，并列时选 sag。
- P2 使用所选动作基下有确认改进的条件，最多 2 个，取收益最大的两个。每个条件的预言码（oracle）是确认收益最大的码。
- 所有动作基都没有确认通过的码时进入决策点 D-1。

**P1：EA 判定。**

- C1-a 设定（回合内固定码）：排除每个回合前 10 步后，执行残差与请求不一致的步数比例记为 p_proj，残差被保护清零的步数比例记为 p_guard。p_proj ≥ 5% 或 p_guard ≥ 5% 时 C1-a 的 EA 判定通过，否则跳过 P3。
- C1-b 设定（开环回放，每 10 步重新采样 u ~ N(0, 0.6²I)）：宏动作定义下，相对仅含 tanh 参数化的参考矩阵 M0，偏差 ‖M − M0‖_F / ‖M0‖_F ≥ 0.3 的决策点比例至少 20%，且线性预测相对误差的中位数 ≤ 0.3 时，C1-b 的 EA 判定通过，否则 P5 改为只报告诊断。

**P2：C1-a 主判定。**

- 每个 session i 在 4 个评估起点上：S_B(i) 为 B 组 20k 快照的完成数，S_A(i) 为零码（等于 A 组 ψ0）的完成数，收益 g_i = (S_B − S_A)/4。
- 每个目标条件内，g 的均值及 95% bootstrap 置信区间（10000 次重抽样，种子 0）。
- 通过条件：至少一个目标条件的平均收益 ≥ 0.10 且置信区间下限 > 0；没有任何条件的置信区间上限 < 0；评估中 B 的安全终止比例不超过 A 加 2 个百分点；平地保持（B 的 20k 码用在平地）完成率下降不超过 5 个百分点，速度均方根误差不超过基础策略的 1.10 倍。
- 次要指标：60k 快照收益、学习曲线、相对预言码收益的比例、训练期最后 4 个回合的完成率（B 对 A）。

## 10. P3 到 P5 的设计要点

这些数值在 P2 结束时，只用 P1、P2 的数据锁定，再写成任务书。

- **C1-b 状态特征 φ(h)**：最近 25 个控制步的投影重力 x、y 均值（2），投影重力水平分量范数的标准差（1），偏航角速度均值（1），关节速度绝对值均值（1），上一个码 z_{k−1}（2），残差被保护清零的步数比例（1），共 8 维，按固定尺度归一化。只用 IMU、关节编码器和过滤器状态，真机都能拿到。
- **C1-b 策略**：μψ = Wφ + b，18 个参数；Σ0 = 0.6²I；Δ = 10 步；回报按前进增量计算，SMDP 折扣 γ = 0.99（每控制步）；基线用同一批次其他回合在同一决策序号上的平均回报，不依赖当前动作。
- **C1-b 组别**：E（Frozen ψ0 = 0）、F（Updated），session、地形、预算和评估方式与 P2 相同；另与 P2-B 在同一批评估起点上比较，检验状态条件是否优于全局码。
- **EA 协方差**：在 M 的特征基下求对角方差，约束 0.2² ≤ s_i ≤ 1.0²、tr(Σ) ≤ 2σ0²、tr(MΣ) ≤ B_exec（取 P1 回放中 tr(M0Σ0) 的中位数），目标 β·tr(MΣ) − λ_n·tr(P_low Σ) − λ_r·‖Σ − Σ0‖²，初值 β = 1、λ_n = 0.5、λ_r = 1，二维网格求解；λ_max < 1e-6、求解不可行或条件数过大时回退 Σ0。
- **EA 组别**：G（Frozen + ΣEA）与 E 比较，排除只改探索带来的当期差异；H（Updated + ΣEA）与 F 比较，是 EA-LPL 的核心增量。
