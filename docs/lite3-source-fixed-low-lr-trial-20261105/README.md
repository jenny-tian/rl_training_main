# Source 固定低学习率两轮对照试验

本阶段已完成并通过预先固定的短时防退化检查。学习率固定为 0.00001 后，第 1、2 轮模型都保留了接近原模型的 8 秒行走表现，未再次出现上一阶段约 23% 的速度下降。当前结论是短时行为保持，尚不能认定地形性能提高或长期训练稳定。

用户在收到详细方案后明确同意执行本阶段，包括两轮训练、两个模型分别复评和必要监控。后续完整回合验证仅提出方案，等待用户同意。本阶段没有自动扩展训练或启动下一阶段。

**这次对照说明了什么。**

实际 runner 配置逐项比较显示，与上阶段仅有两项差异：初始学习率由 0.001 改为 0.00001，调度由 adaptive 改为 fixed。其余 PPO 参数、网络结构、初始化、奖励、地形和种子保持一致。训练前 actor 全部张量与原 checkpoint 相等，初始动作均值最大误差为 0。

第 1 轮更新前已记录的采样摘要与上阶段逐项完全相等，包括平均奖励、平均速度、裁剪比例、结束数，以及 critic 预测、return 目标、均方误差和 advantage 统计。这使首次更新后的行为差异有明确的对照依据。

| 训练记录 | 第 1 轮 | 第 2 轮 |
|---|---:|---:|
| 实际学习率 | 0.00001 | 0.00001 |
| 平均采样奖励 | 0.070572 | 0.087989 |
| 采样时平均速度 m/s | 0.222510 | 0.269830 |
| 探索标准差均值 | 0.343143 | 0.343135 |
| 采样动作裁剪比例 | 0.03472% | 0.01447% |
| critic 预测均值 | 0.008929 | 0.073153 |
| return 目标均值 | 0.641497 | 0.799013 |
| 更新前 critic 均方误差 | 0.473584 | 0.625309 |

采样每轮只有 0.48 秒仿真时间，两轮共 0.96 秒/环境，包含启动过程和探索噪声。训练均值不能替代确定性复评，也不能据此声称长时训练已收敛。critic 仍存在较大的预测偏差；由于共享 optimizer，此次同时降低了 actor 与 critic 的学习率，不能独立认定某一个网络是唯一原因。

结合配置对照、首次采样摘要和实际复评，本次结果支持学习率策略是上一阶段明显退化的重要因素。它没有证明固定 0.00001 在更多更新后仍然稳定，也没有证明该值是最优学习率。
