# 六类地形奖励修正：代码与仿真验证阶段

本阶段实施了两个核心修正，并准备三个独立足端奖励变体。所有修改位于当前项目，`/home/tjx/rl_training` 和 Isaac Lab 依赖保持只读。本阶段只做默认站姿校准、冻结模型检查和测试，没有训练更新，也没有修改既有检查点。

## 已实施的核心修正

### 原地转向不再触发站立惩罚

`scripts/tools/reference_reward_variants.py` 新增 `stand_still_joint_deviation_se2`。站立条件同时要求：

- 平面线速度指令模长小于 0.1 m/s；
- 转向角速度指令绝对值小于 0.1 rad/s。

两个阈值分开判断，避免将米/秒和弧度/秒直接混合。纯左转、纯右转、前进和侧移指令均不再被误判为站立；零指令仍保留原来的关节偏离惩罚。保留原关节选择、L1 公式和 -0.5 权重。

### 机身高度目标从 0.55 m 校准为 0.32 m

保留原 `base_height_l2` 函数、-50 权重、地面扫描器及课程系数，只修改目标值。使用原机器人、原默认关节目标和原 PD 执行器，在平地上对 64 个环境运行 6 秒默认姿态控制。名义质量/惯量/质心/增益、固定 0.9 摩擦，保留原执行器延迟；关闭观测噪声和其他物理随机化。

最后 1 秒，机身相对 `height_scanner_base` 地面均值的高度为：平均 0.320064 m、中位数 0.319295 m、最小 0.318191 m、最大 0.322565 m。目标 0.32 m 与实际承重站姿吻合。

该数值是本机型当前 PD 和默认站姿下的初始校准值，不意味着爬阶时每一步都必须保持 0.32 m；这是软奖励。地面基准仍使用原扫描器平均值，其在台阶边缘的适用性还需要后续行为验证。本阶段没有同时更换高度函数或权重。

## 独立配置与用途

| 配置名称 | 相对原奖励的改动 | 用途 |
|---|---|---|
| `reference` | 无 | 复现历史配置；不安排原奖励续训 |
| `stand_gate` | 仅修正站立门控 | 判断转向门控的单独贡献 |
| `height_target` | 仅将高度目标改为 0.32 m | 判断高度冲突的单独贡献 |
| `core` | 上述两项一起修正 | 核心修正版本 |
| `core_no_phase` | 核心修正 + 固定足端轨迹权重置零 | 检查固定轨迹对抬脚和转向的限制 |
| `core_airtime_nonnegative` | 核心修正 + 两个腾空时间项逐脚去除负值 | 检查短步落地惩罚的影响 |
| `core_no_gait` | 核心修正 + 原步态项权重置零 | 检查静态接触仍获步态分数的影响 |

三个足端变体各自只在 `core` 上增加一组相关改动，不互相叠加。核心版本仍保留原足端轨迹、腾空时间和步态奖励，不能把实验变体描述为已经证明有效的改进。

腾空时间变体按每只脚计算 `max(腾空时间 - 0.5 s, 0)`，再仅在首次落地时求和。短步和始终站立都得零；大于 0.5 秒的腾空落地仍保留原正奖励。线速度/转向门控、阈值、权重和全局课程系数保持原值。逐脚截断可避免一个短步的负值抵消另一只脚的有效长步；它本身并不新增短步奖励。

移除固定足端轨迹或原步态项，也会失去这些项原先提供的步态引导。因此这两个配置仅用于对照，是否保留必须看跨阶、转向和平地步态结果。

## 配置隔离与训练入口

`apply_reward_variant()` 深拷贝参考配置，并检查完整环境字典：只有所选奖励项可以变化；命令分布、六类地形及份额、观测、动作、终止条件和物理配置均不能由奖励覆盖层改动。每次调用返回逐项修改前后记录和配置哈希，不会改变其他变体或参考配置。

`reference_six_train.py` 已接入显式参数 `--reward-variant`，分别保存原始参考一致性审计和 `reward_override_audit.json`，并将最终环境配置写入 `params/env.yaml`。默认仍为 `reference` 以保留历史入口；之后启动修正版必须明确选择配置。

该入口默认从头初始化；本阶段新增显式 `--resume-final`，只允许加载已审查的最终 10000 次更新检查点，并校验固定 SHA256。它完整恢复 actor、critic、Adam 动量与计数，并逐项比较加载前后的保存状态。

还修正了恢复流程中两个容易出错的细节：原库的加载函数只恢复 Adam 参数组的学习率，不会恢复 PPO 自适应学习率标量，因此显式同步为检查点中的 0.0002562890625；检查点 `iter=9999` 是从零计数，下一个训练迭代必须从 10000 开始。原 Adam 步数为 200000，后续预算完成时再核对增量。

续训时必须明确选择修改后的奖励，禁止 `reference` 原奖励续训；必须显式指定 1～500 次更新，省略预算或超过上限都会在启动模拟器前拒绝。`--mode smoke --resume-final` 只执行 100 个零动作控制步，并校验模型和优化器状态完全不变。没有执行任何训练更新。环境、地形初始等级和随机数状态重新按种子初始化，不能把它称为训练历史的逐位连续恢复。

## 固定行为验收

原地左右 0.2/0.5/0.8 rad/s、停止、反向、左右 90°航向、前进转弯和平地前进继续使用 `reference_turn_diagnose.py` 的固定协议。每种物理条件 16 类 × 20 起点 = 320 回合，名义参数和训练随机化分别统计。

`reference_isaac_stairs_diagnose.py` 新增 `--direction up|down`，默认上台阶保留旧判据。下台阶使用原生方形凸台，从顶部平台向外逐级下降；由射线实际测得的边缘和踏面高度判定进度。首级与整段下降必须有支撑、躯干未触地、四脚跨过边缘并处于较低踏面附近，防止空中越过边缘被计为成功。分析文件增加方向字段，下降轨迹图支持负的相对高度。

正式验收矩阵固定为 0/5/10/15 cm × 0.32/0.4/0.6 m/s × 20 起点 × 名义参数/训练随机化。上下台阶各 480 回合，其中分别包含平地对照；加转向 640 回合，每个候选模型共 1600 个正式回合。当前脚本固定使用已有检查点；未来新检查点接入时必须记录模型哈希，保持起点和指标口径一致。

本阶段的上下台阶短程运行仅验证协议和几何，不能用作上述完整行为验收。本阶段也没有宣称模型已经学会爬阶或左转已经恢复，奖励代码修改不会立即改变冻结网络的动作。
